# Docs

Contributor pages for this presence site. Topic pages stay where they are. The changelog stays at `CHANGELOG.md`.

The presence site, the gallery, ventures, and the garden share one token set (`src/tokens.css`, `docs/tokens.json`, `docs/design.md`). Slides are a local spike and are not deployed. `docs/tokens.json` is the token values as JSON. It is not a Markdown page, so it is named here and not in the generated list.
